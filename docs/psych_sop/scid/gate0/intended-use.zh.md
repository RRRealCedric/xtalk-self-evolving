# Intended Use 与产品边界

## 一句话定位

X-Talk SCID 是一个使用 SCID 式结构化提问纪律的非诊断性对话研究原型，目标是以低门槛方式帮助用户梳理情绪和心理体验、时间过程、频率、情境与生活影响，并在需要时提供分级的下一步选择。

SCID-5 官方将 SCID 描述为用于形成 DSM-5 诊断的半结构化访谈指南。正因其原始用途具有诊断性质，本项目必须把“借鉴或使用其结构化访谈方法”与“由系统给出诊断”严格分离，并在完成来源、许可和专业审查前维持 research-only。[Columbia Psychiatry: SCID-5](https://www.columbiapsychiatry.org/research/research-labs/diagnostic-and-assessment-lab/structured-clinical-interview-dsm-disorders-11)

## 用户价值

项目希望提供的不是“AI 精神科医生”，而是以下体验：

- 用户无需先确认自己是否“严重到需要看病”，就可以开始表达；
- 对话用结构化方式帮助用户把模糊的“烦躁、不舒服、最近状态不对”拆成更清楚的体验、时间、频率、触发、身体反应和生活影响；
- 用户可以修正、补充、跳过、暂停或结束，不因回答不完整而被迫接受结论；
- 普通压力、烦躁和短暂情绪波动不会被自动解释为精神障碍，也不会自动触发精神科转诊；
- 当困扰持续、加重、反复或明显影响功能时，系统可以解释为什么进一步的人类专业支持可能有帮助，但决定权保留给用户；
- 当存在紧迫安全风险时，普通结构化访谈让位于安全支持和人工/紧急资源。

WHO 将压力描述为常见的人类反应，并提供可自行使用的压力管理材料；这支持“普通困扰不等于自动需要精神科诊断”的分级思路，但不证明本项目本身有效。[WHO: Stress](https://www.who.int/news-room/questions-and-answers/item/stress)、[WHO: Doing What Matters in Times of Stress](https://www.who.int/publications/i/item/9789240003927)

## 当前允许用途

在 D0 Gate 0 基线完成、Gate 1/2/3 未完成时，仅允许：

- 开发者本地功能开发；
- 合成对话、明确无真实个人健康信息的测试数据；
- 来源、用途和处理条件均可证明的去标识化研究数据；
- 评估结构化提问、状态机、并发、延迟和非诊断表达；
- 生成供研究者审查的内部字段状态、候选证据元数据和结构化回放记录；对话原文回放默认关闭，仅在明确数据条件下 opt-in。

这些内部 `score`、`field_state` 或 `AssessmentDecision` 是研究状态，不是病历、诊断、医学意见或面向用户的疾病结论。

## 目标人群

首版研究范围暂定为：

- 能理解并自愿参与中文语音/文本对话的成年人；
- 希望梳理压力、烦躁、担心、害怕、睡眠变化或其他主观困扰的人；
- 能够理解系统是非诊断工具，且可以随时退出的人。

以下人群或情境在建立专门协议前排除：

- 未成年人；
- 无法形成有效知情同意的人；
- 正处于自伤、他伤或其他立即危险的人；
- 需要紧急医学、精神科或现场处置的人；
- 试图用系统替代处方、停药、用药调整、住院或其他医疗决定的人；
- 法医、保险、就业、教育资格、司法、强制评估或其他高影响决策；
- 未满足适用条件的真实患者招募、临床分流或诊疗工作流。

## 输出边界

允许的用户可见输出：

- 非诊断性的倾听、复述和结构化澄清；
- 对用户自己所述体验、时间、频率、情境和影响的中性整理；
- 说明信息仍不充分并继续询问；
- 说明系统能力与局限；
- 分级、非强迫的下一步选择；
- 紧迫风险时的安全优先提示。

禁止的用户可见输出：

- “你患有/没有某精神障碍”或同等确定性结论；
- 用内部 `? / 1 / 2 / 3`、字段编号或模块跳转冒充医学结果；
- 保证“你不需要就医”或“你一定需要精神科就诊”；
- 药物、停药、剂量、住院或其他医疗处置建议；
- 用诊断标签解释用户身份、人格、道德或未来；
- 将普通烦躁、压力、悲伤或关系冲突自动病理化；
- 以系统输出支持就业、保险、司法、教育或其他高影响决定。

## 分级响应规则

### L0：普通困扰或生活压力

适用示例：短暂烦躁、工作压力、关系冲突、偶发担心，且用户仍可应对，没有紧迫安全风险或明显功能崩溃。

系统行为：倾听、澄清、帮助组织体验；可以提供经审核的低风险自助选项，但当前 SCID 原型尚未实现完整自助干预库。不得自动贴标签或强制建议精神科。

### L1：持续或显著困扰

适用示例：困扰持续、反复、加重，明显影响睡眠、工作、学习、关系或自我照料，但没有立即危险。

系统行为：继续非诊断梳理；说明人类专业人员能提供更完整评估；提供可选择的心理咨询、基层医疗或精神健康服务路径。具体地区、资质和服务目录必须另行审核。

### L2：紧迫安全风险

适用示例：当前自伤/他伤意图、计划、手段、迫近实施或其他需要立即现场帮助的情况。

系统行为：立即停止普通 SCID 流程；用直接、简短、非评判语言优先安全；鼓励联系当地紧急服务、可信任的人或具备危机处置能力的专业人员。系统不得声称自己正在监控、已经报警或能够提供现场救援，除非未来确有经验证的人工接管能力。

当前关键词 `SafetyGuard` 不足以证明 L2 识别可靠，地区化资源也未完成。因此这一层是阻塞真实用户试点的硬门禁。

## 用户说明草案

启动时应明确表达：

> 这是一次用结构化问题帮助你梳理感受和生活影响的非诊断性对话。它不会因为普通的烦躁或压力就给你贴标签，也不能替代医生或心理治疗师。你可以随时暂停或结束；如果你正处于立即危险，请优先联系当地紧急服务或身边可信任的人。

当前 runtime 会把这段开场说明，以及停止、L2 危机和自然完成话术，作为版本化确定性文本执行；这些路径不调用外部 Dialogue Model，也不允许模型改写产品边界。这只保证关键话术稳定，不证明 SafetyGuard 能正确识别所有危机语境。

真实研究还必须在开始前说明：数据收集内容、用途、供应商、留存期限、删除方式、退出后如何处理已收数据，以及人工联系人。当前这些条件尚未满足，不得把上述启动文案单独视为有效知情同意。

## 停止条件

系统必须停止普通访谈，当：

- 用户明确要求停止或撤回同意；
- 出现 L2 紧迫安全风险；
- 系统无法维持正确字段、数据完整性或安全边界；
- 外部模型、ASR、TTS 或存储故障导致安全回复无法可靠送达；
- 检测到错误诊断宣称、敏感数据越权外发或其他硬门禁违反；
- 研究协议规定的时长、次数或人群边界已达到。

## 声明边界

当前可以说：

> 这是一个受 SCID 结构化访谈方法启发、用于研究非诊断性支持体验的工程原型。

当前不可以说：

> 这是经过临床验证的 SCID 自动访谈、筛查、诊断、分诊或治疗系统。
